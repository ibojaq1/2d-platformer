# BetCode Landing Page

A dark-themed landing page for **BetCode** — an AI-powered Telegram bot that converts NerdyTips predictions into SportyBet booking codes.

## Features

- Sticky nav with blur backdrop
- Animated hero section with stats bar
- Interactive terminal demo (typing animation)
- "How it works" step cards
- Market tags showcase
- Pricing cards (Free / Premium)
- Testimonials grid
- Accordion FAQ
- CTA section with gradient glow
- Fully responsive (mobile-first breakpoints)

## Tech Stack

- Vanilla HTML / CSS / JS (no frameworks)
- Google Fonts: Outfit + JetBrains Mono
- CSS custom properties for theming
- IntersectionObserver for scroll-reveal animations

## Getting Started

Open `index.html` in a browser, or serve locally:

```bash
npx serve .
```
